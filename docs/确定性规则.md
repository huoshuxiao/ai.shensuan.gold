# 确定性规则

「确定性规则」指：事先写成公式和阈值的「如果…就…」规则；同样的数据输入，永远得到同样的输出。它不靠模型临场感觉、不随机、不编数字，因此能被逐行复核，也能拿历史数据回测。

在这套黄金系统里，确定性规则主要包括：

- 趋势规则：例如收盘价高于"200日均线"（过去200个交易日收盘价的平均）就维持基础仓位，低于就降一档。
- 数据新鲜度规则：关键数据超过约定天数没更新 → 禁止加仓，只能维持或减仓。
- 风险规则：年化波动率超过阈值 → 降仓；从高点回撤达到 10% → 减一档，达到 15% → 再减一档。
- 仓位带规则：规则先算出今天卫星仓只允许在 10%–20% 之间，这是硬边界。
- 交易规则：T+1、ETF 100份一手、手续费和滑点、单日最多加 10 个百分点等。
- 逆向情绪规则：COT 持仓、ETF 资金流、RSI 等达到极端值时，只按预先写好的公式给出"贪婪/恐惧"读数，不靠模型自由发挥。

多智能体辩论仍然有真实权力，但被限制在这条带内：

- 规则给出 10%–20%，组合经理辩论后可以选 10%、15% 或 20%，也可以选择减到 0；
- 如果它说"加到 40%"，系统会把结果夹回 20%；
- 风控经理可以一票否决，直接把卫星仓降到 0；
- 数据过期或缺失时，只能维持或减仓，不能加仓。

这样做的原因：每一分仓位都能回答"用了哪天的数据、哪条公式、哪个阈值、哪次辩论、谁否决"。历史回测只能回测确定性规则；LLM 的判断没法回到过去重跑，所以它只能在纸面跟踪里向前验证。

注意：**确定性不等于一定赚钱**。它只保证"不随机、可复核、可回测"；这套规则是否有效，仍要通过 **样本外回测** 和 **纸面跟踪** 来证明。
